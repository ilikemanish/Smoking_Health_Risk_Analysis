# 📌 Project Overview

**Smoking Health Risk Analysis** is an interactive **Power BI data analytics project** designed to explore smoking behaviour, patient demographics, organ conditions and related health-risk indicators.

The project analyzes a dataset containing **2,500 patient records** and uses Power BI to transform structured healthcare-related data into interactive KPIs, slicers and visualizations.

The dashboard allows users to explore the data by:

- 🚬 Smoking Status
- 🫀 Organ
- 🩺 Organ Condition
- 👤 Age Group
- ⚧ Gender
- 🩸 Blood Pressure Risk
- 🧪 Cholesterol Level
- 🧬 Family History Risk
- 🍺 Alcohol Consumption
- 🚬 Cigarettes Per Day
- 📅 Years of Smoking

> **Important:** This is a data analytics project based on the supplied dataset. It is not a medical report and should not be used for diagnosis or individual medical-risk assessment.

# 💡 Key Analytical Findings

### 1. Dataset Composition

The project contains **2,500 patient records**, with **35.9% labelled Damaged** and **64.1% labelled Healthy**. 9

### 2. Smoking Status

Never smokers form the largest smoking-status group in the supplied dataset, followed by Current and Former smokers. 10

### 3. Smoking Exposure

Current smokers have the highest average cigarettes-per-day value and longest average recorded smoking duration among the three smoking-status groups. 11

### 4. Organ Analysis

Damage rates across the five organ categories range from approximately **32.7% to 37.7%** in the supplied dataset. 12

### 5. Age Analysis

Observed damage rates vary across age groups, ranging from **32.4% to 40.0%**. These are descriptive differences within the supplied dataset. 13

# ⚠️ Limitations & Responsible Interpretation

This project is intended for **data analytics and dashboard demonstration**.

Important limitations include:

- The dataset source is not documented.
- The sampling strategy is not documented.
- The collection period is not documented.
- The clinical definition of the `Healthy/Damaged` label is not provided.
- The supplied data may be synthetic, simulated or project-generated.
- The analysis does not establish causation.
- Dashboard values change according to slicer selections.
- Cholesterol and BP-risk values are used as supplied and are not medical diagnoses.

Therefore, the results should be interpreted as **descriptive analysis of the supplied project data**, not as medical evidence or population-level estimates. 14

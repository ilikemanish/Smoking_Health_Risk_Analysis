📌 Project Overview

Smoking Health Risk Analysis is an interactive Power BI healthcare analytics project developed to analyse smoking behaviour and its relationship with different demographic and health-related indicators.

The dashboard provides an interactive view of patient data using factors such as:

- 🚬 Smoking Status
- 👥 Gender
- 🎂 Age Group
- ⏳ Years of Smoking
- 🚬 Cigarettes Per Day
- ❤️ Blood Pressure Risk
- 🧪 Cholesterol Level
- 🫀 Organ Conditions

The project demonstrates how Power BI, data modelling, DAX, and interactive visualization can transform healthcare data into meaningful analytical insights.

🔍 Key Insights

The dashboard enables exploration of several important analytical patterns:

🚬 Smoking Behaviour

- Comparison of smoking status across demographic groups
- Analysis of smoking duration
- Examination of daily cigarette consumption
- Identification of differences between age groups

❤️ Health Risk Indicators

- Distribution of blood-pressure risk categories
- Comparison of cholesterol levels
- Exploration of health indicators across age groups

🫀 Organ Health

- Analysis of different organs represented in the dataset
- Exploration of associated organ conditions
- Interactive filtering for deeper investigation

«Note: The dashboard is intended for exploratory data analysis. Exact numerical conclusions should be interpreted directly from the Power BI dashboard and underlying dataset.»

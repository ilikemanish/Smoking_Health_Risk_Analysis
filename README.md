📌 Project Overview

This project is an interactive Smoking Health Risk Analysis Dashboard developed using Microsoft Power BI.

The dashboard explores smoking behaviour and its relationship with different demographic and health-related indicators. It provides an interactive view of patient data using smoking status, age group, gender, years of smoking, cigarettes per day, blood-pressure risk, cholesterol level, and organ conditions.

The project demonstrates how Power BI can transform healthcare data into meaningful visual insights for exploratory and business-style analysis.

🎯 Project Objectives

The main objectives of this project are to:

- 🩺 Analyze smoking patterns across patients
- 🚬 Compare different smoking-status groups
- 👥 Analyze smoking behaviour by gender
- 📅 Study smoking exposure across age groups
- 🚬 Analyze years of smoking and cigarettes consumed per day
- ❤️ Explore blood-pressure risk categories
- 🧪 Compare cholesterol levels across risk groups
- 🫁 Analyze organ-related health conditions
- 🔎 Provide interactive filtering for focused analysis
- 📊 Build an easy-to-understand healthcare analytics dashboard

🗂️ Data Model

The dashboard uses patient-level healthcare and smoking-related attributes.

Key Fields

"Organ_Condition"| Organ-related health condition

💡 Key Analytical Insights

The dashboard provides a framework to investigate several important healthcare questions.

🚬 Smoking Behaviour

Analyze the distribution of patients across different smoking-status categories and compare the relative size of each group.

📅 Smoking Exposure

Compare years of smoking and cigarettes consumed per day across age groups to understand differences in smoking exposure.

👥 Gender-Based Analysis

Explore how smoking-status composition varies between different genders.

❤️ Blood Pressure & Cholesterol

Compare average cholesterol levels across age groups and blood-pressure-risk categories to identify patterns that may require further investigation.

🫁 Organ Conditions

Use organ and condition filters to investigate health conditions across different patient segments.

«Note: The dashboard identifies patterns and associations within the dataset. It does not establish that smoking directly caused a particular health outcome.»
